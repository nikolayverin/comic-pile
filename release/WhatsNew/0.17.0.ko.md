**기능**

**설정**
- **설정 -> 일반**에 **앱 언어** 옵션을 추가했습니다.
- 첫 실행 시 지원되는 시스템 언어를 사용할 수 있습니다.
- 영어, 스페인어, 독일어, 프랑스어, 일본어, 한국어, 중국어 간체용 인터페이스 텍스트와 온보딩 에셋을 추가했습니다.

**도움말 및 릴리스 노트**
- **도움말**과 **새로운 기능**이 선택한 앱 언어를 따르며, 없으면 영어로 대체됩니다.

**업데이트**
- 내장 업데이트가 이제 스타터 라이브러리를 다시 다운로드하지 않는 더 작은 업데이트 패키지를 사용할 수 있습니다.
- 업데이트 팝업에 사용 가능한 업데이트, 다운로드 진행 상황, 설치에 대한 설명을 더했습니다.
- 업데이트 다운로드 팝업이 다운로드된 크기와 설치 준비 상태를 더 명확하게 보여줍니다.

**가져오기**
- 가져오기가 진행되는 동안에도 라이브러리를 둘러보거나 이미 가져온 만화를 읽을 수 있습니다.
- 사이드바와 리더에 간단한 가져오기 진행 상태를 추가하고, 전체 가져오기 팝업을 다시 열 수 있게 했습니다.

**시리즈**
- 시리즈에 선택적 색상 태그를 추가하고, **라이브러리** 사이드바에서 해당 태그로 필터링할 수 있게 했습니다.

**버그 수정**

**가져오기**
- 시리즈 이름과 번호만 반복하는 파일명이 더 이상 **제목** 필드를 채우지 않도록 수정했습니다.
- 가져오기 취소 중에도 Comic Pile이 계속 반응하고 취소된 가져오기 묶음을 더 예측 가능하게 정리하도록 수정했습니다.
- 가져오기 취소 중 기존 시리즈의 표지와 이슈 그리드가 사라지지 않도록 수정했습니다.

**업데이트**
- 팝업 밖을 클릭하거나 **Esc**를 누르거나 닫기 버튼을 사용해도 업데이트 다운로드가 실수로 취소되지 않도록 수정했습니다.
- 내장 업데이트 후 앱을 다시 시작해도 첫 실행 투어가 다시 표시되지 않도록 수정했습니다.

**라이브러리**
- 시리즈 이름 편집으로 아카이브가 이름이 바뀐 폴더로 이동해도 이슈 표지와 hero 표지가 계속 보이도록 수정했습니다.
- 보이는 그리드 표지가 더 자연스럽게 위에서 아래 순서로 나타나도록 표지 로딩을 개선했습니다.

**인터페이스**
- 긴 번역 레이블과 메시지가 더 안정적으로 맞고 읽히도록 현지화된 팝업 레이아웃을 개선했습니다.
- 창이 화면 밖에 열렸을 때도 복구하기 쉽도록 온보딩을 **Esc**로 닫고 화살표 키로 이동할 수 있게 했습니다.
