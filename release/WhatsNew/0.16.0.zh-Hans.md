**功能**

**语言和本地化**
- 在 **设置 -> 常规** 中新增 **应用语言** 选项。
- Comic Pile 现在可以在首次启动时使用受支持的系统语言。
- 为顶部栏、阅读器、弹窗、设置、元数据对话框、帮助和新增内容加入了本地化文本。
- 新增英语、西班牙语、德语、法语、日语、韩语和简体中文的入门引导资源。

**帮助和版本说明**
- 帮助内容现在来自内置的本地化数据文件，而不是单一硬编码 UI 副本。
- **帮助** 和 **新增内容** 现在会跟随所选应用语言，并回退到英语。
- 新增补丁说明编写规则，确保后续更新保留版本历史。

**更新和便携版**
- 应用设置现在更一致地使用便携式 **ComicPile.ini** 配置文件。
- 改进更新弹窗，更清楚地说明可用更新、下载进度和安装状态。
- 加强便携式更新安装流程，使更新更可预测，同时保留现有资料库数据和设置。

**发布包**
- 便携包中包含内置 **DjVu** runtime 支持。
- 发布包生成过程更加确定。

**修复**

**界面**
- 从应用窗口标题中移除了 prototype 标签。
- 改进本地化弹窗布局，使较长的翻译标签和消息更容易适配和阅读。
- 移除过期 placeholder 标签，并修正常见拼写错误的资源路径。

**设置和入门引导**
- 移除重复的默认阅读模式设置。
- 重置设置时不再意外重置入门引导状态。
- 入门引导现在可用 **Esc** 关闭，并可用方向键导航。

**阅读器和验证**
- 移除阅读器验证流程中的 QML warning。
