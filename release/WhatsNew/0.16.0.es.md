**Funciones**

**Idioma y localización**
- Se añadió la opción **Idioma de la app** en **Ajustes -> General**.
- Comic Pile puede usar un idioma del sistema compatible en el primer inicio.
- Se añadió texto localizado para la barra superior, lector, popups, ajustes, diálogos de metadatos, Ayuda y Novedades.
- Se añadieron recursos de onboarding localizados para inglés, español, alemán, francés, japonés, coreano y chino simplificado.

**Ayuda y notas de versión**
- El contenido de Ayuda ahora vive en archivos de datos localizados incluidos con la app, no en una única copia de UI hardcodeada.
- **Ayuda** y **Novedades** ahora siguen el idioma seleccionado, con fallback a inglés.
- Se añadieron reglas para escribir notas de parche, para que las futuras actualizaciones conserven historial de versiones.

**Actualizaciones y app portable**
- Los ajustes de la app ahora usan de forma más consistente el archivo portable **ComicPile.ini**.
- Se mejoraron los popups de actualización con contexto más claro para versiones disponibles, progreso de descarga e instalación.
- Se reforzó el flujo de instalación de actualizaciones portables para aplicarlas de forma más predecible conservando biblioteca y ajustes.

**Paquete de release**
- Se incluyó soporte runtime **DjVu** en el paquete portable.
- La generación del paquete de release ahora es más determinista.

**Correcciones**

**Interfaz**
- Se eliminó la etiqueta de prototipo del título de la ventana.
- Se mejoraron layouts localizados para que textos largos encajen y se lean mejor.
- Se eliminaron etiquetas placeholder obsoletas y se normalizaron rutas de assets con errores tipográficos.

**Ajustes y onboarding**
- Se eliminó una opción duplicada de modo de lectura por defecto.
- Restablecer ajustes ya no reinicia el estado de onboarding por accidente.
- El onboarding ahora puede cerrarse con **Esc** y navegarse con flechas.

**Lector y validación**
- Se eliminaron warnings QML del flujo de validación del lector.
