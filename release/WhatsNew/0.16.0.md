**Features**

**Language and localization**
- Added an **App language** option in **Settings -> General**.
- Comic Pile can now use a supported system language on first launch.
- Added localized interface text for the top bar, reader chrome, popups, settings, metadata dialogs, Help, and What's new.
- Added localized onboarding assets for English, Spanish, German, French, Japanese, Korean, and Chinese Simplified.

**Help and release notes**
- Help content now lives in bundled localized data files instead of a single hardcoded UI copy.
- **Help** and **What's new** now follow the selected app language, with English fallback.
- Added patch-note writing rules so future updates keep version history instead of replacing it silently.

**Updates and portable app**
- App settings now use the portable **ComicPile.ini** config more consistently.
- Improved update popups with clearer context for available updates, download progress, and installation.
- Hardened the portable update install flow so updates apply more predictably while keeping existing library data and settings.

**Release package**
- Included bundled **DjVu** runtime support in the portable package.
- Made release packaging more deterministic.

**Bugfixes**

**Interface**
- Removed the prototype label from the app window title.
- Improved localized popup layouts so longer translated labels and messages fit and read more reliably.
- Removed stale placeholder labels and normalized misspelled asset paths.

**Settings and onboarding**
- Removed a duplicate default reading mode setting.
- Resetting settings no longer resets the onboarding state by accident.
- Onboarding can now be closed with **Esc** and navigated with arrow keys, making it easier to recover if the window opens off-screen.

**Reader and validation**
- Removed QML warnings from the reader validation flow.
