**Funciones**

**Actualizaciones**
- Se añadió una acción visible **Buscar actualizaciones** en **Acerca de**.
- Se añadió la opción **Buscar actualizaciones automáticamente** en **Configuración -> General**, manteniendo también la búsqueda manual.
- Se añadió un flujo dedicado de actualización con **Actualización disponible**, **Descargando actualización**, **Instalar actualización** y la pantalla interna **Novedades**.
- Se añadió un aviso único para versiones recién detectadas, y las actualizaciones disponibles conocidas siguen visibles en **Acerca de** entre inicios.
- **Instalar actualización** ahora cierra Comic Pile, aplica la actualización portable descargada sobre la carpeta actual de la app y conserva los datos existentes de **Database** y el archivo de configuración **ComicPile.ini**.
- Se añadió una sección dedicada **Actualizar Comic Pile** en la Ayuda, con explicación de comprobaciones, comportamiento automático, descarga e instalación, y guía manual para la versión portable.

**Importación**
- **Reemplazar** ahora puede usar una carpeta de imágenes de páginas ordenadas, no solo otro archivo comprimido.
- La entrada de Ayuda de **Reemplazar** se actualizó para coincidir con el flujo actual de la app.

**Correcciones**

**Paquete de lanzamiento**
- Se corrigió el paquete portable para que el soporte **DjVu** incluido viaje con la app.

**Actualizaciones**
- Se ajustó el diseño del popup **Descargando actualización** y se corrigió la animación de progreso de un solo elemento para que la barra se mantenga estable dentro del contenedor redondeado.
- Se corrigió el estado fallido en **Descargando actualización** para que la barra deje de animarse después de un error y las descargas fallidas simuladas ya no lleguen engañosamente al 100%.

**Biblioteca y series**
- Se corrigió el comportamiento de la portada principal en series muy grandes para que no falle al invertir el orden de los números.
- Se mejoró la mezcla del fondo principal en series muy grandes limitando los candidatos y reduciendo repeticiones rápidas.
- Los archivos temporales de vista previa del fondo mezclado ahora se limpian cuando se elimina la serie relacionada.
- Se corrigió la caché de portadas para que mover la carpeta de datos de la biblioteca no obligue a regenerar portadas solo porque cambió la ruta absoluta.
- El pulgar arrastrable de la barra de desplazamiento de la cuadrícula vuelve a funcionar correctamente.
- Las series normales en la barra lateral ya no muestran siempre **Vol. 1** cuando ese valor es solo un volumen técnico predeterminado.

**Metadatos**
- Se corrigieron los títulos importados para que los nombres de archivo que solo repiten la serie y el número ya no llenen el campo **Título**.
- Los números normales de edición ya no conservan ceros técnicos como 000, 001 o 002.
- También se normalizaron números con prefijo, de modo que valores como **Annual 001** se guardan de forma más limpia como **Annual 1**.
