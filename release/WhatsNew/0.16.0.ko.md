**기능**

**언어 및 현지화**
- **설정 -> 일반**에 **앱 언어** 옵션을 추가했습니다.
- 첫 실행 시 지원되는 시스템 언어를 사용할 수 있습니다.
- 상단 바, 리더, 팝업, 설정, 메타데이터 대화상자, 도움말, 새로운 기능 화면에 현지화된 텍스트를 추가했습니다.
- 영어, 스페인어, 독일어, 프랑스어, 일본어, 한국어, 중국어 간체 온보딩 에셋을 추가했습니다.

**도움말 및 릴리스 노트**
- 도움말 콘텐츠는 이제 하나의 하드코딩된 UI 복사본이 아니라 번들된 현지화 데이터 파일에서 로드됩니다.
- **도움말**과 **새로운 기능**은 선택한 앱 언어를 따르며 영어 fallback을 사용합니다.
- 이후 업데이트에서 버전 기록을 유지할 수 있도록 패치 노트 작성 규칙을 추가했습니다.

**업데이트 및 포터블 앱**
- 앱 설정이 포터블 **ComicPile.ini** 설정 파일을 더 일관되게 사용합니다.
- 사용 가능한 업데이트, 다운로드 진행률, 설치 상태를 더 명확히 보여주도록 업데이트 팝업을 개선했습니다.
- 기존 라이브러리 데이터와 설정을 유지하면서 포터블 업데이트를 더 예측 가능하게 적용하도록 설치 흐름을 강화했습니다.

**릴리스 패키지**
- 포터블 패키지에 번들 **DjVu** runtime 지원을 포함했습니다.
- 릴리스 패키징을 더 결정적으로 만들었습니다.

**버그 수정**

**인터페이스**
- 앱 창 제목에서 prototype 라벨을 제거했습니다.
- 긴 번역 라벨과 메시지가 더 안정적으로 들어가고 읽히도록 현지화된 팝업 레이아웃을 개선했습니다.
- 오래된 placeholder 라벨을 제거하고 오타가 있던 에셋 경로를 정리했습니다.

**설정 및 온보딩**
- 중복된 기본 읽기 모드 설정을 제거했습니다.
- 설정 초기화가 온보딩 상태를 실수로 초기화하지 않도록 수정했습니다.
- 온보딩을 **Esc**로 닫고 방향키로 이동할 수 있게 했습니다.

**리더 및 검증**
- 리더 검증 흐름의 QML warning을 제거했습니다.
