**Funciones**

**Configuración**
- Se añadió la opción **Idioma de la app** en **Configuración -> General**.
- Comic Pile ahora puede usar un idioma del sistema compatible en el primer inicio.
- Se añadieron textos de interfaz y recursos de onboarding localizados para inglés, español, alemán, francés, japonés, coreano y chino simplificado.

**Ayuda y notas de versión**
- **Ayuda** y **Novedades** ahora siguen el idioma seleccionado de la app, con inglés como reserva.

**Actualizaciones**
- Las actualizaciones integradas ahora pueden usar un paquete más pequeño sin volver a descargar la biblioteca inicial.
- Se mejoraron los popups de actualización con más contexto sobre actualizaciones disponibles, progreso de descarga e instalación.
- El popup de descarga de actualización ahora muestra el tamaño descargado y un estado más claro cuando está listo para instalar.

**Importación**
- Las importaciones ahora pueden seguir ejecutándose mientras navegas por la biblioteca o lees cómics ya importados.
- Se añadió progreso compacto de importación en la barra lateral y en el lector, con una forma de volver a abrir el popup completo.

**Series**
- Se añadieron etiquetas de color opcionales para series, con un filtro en la barra lateral de **Biblioteca**.

**Correcciones**

**Importación**
- Se corrigieron los títulos importados para que los nombres de archivo que solo repiten serie y número ya no rellenen el campo **Título**.
- Se corrigió la cancelación de importación para que Comic Pile responda mejor y limpie el lote cancelado de forma más predecible.
- Se corrigió la cancelación de importación para que las portadas y cuadrículas de series existentes no desaparezcan durante la limpieza.

**Actualizaciones**
- Se corrigieron las descargas de actualización para que hacer clic fuera del popup, pulsar **Esc** o usar el botón de cierre ya no cancele la descarga por accidente.
- Se corrigieron las actualizaciones integradas para que Comic Pile no vuelva a mostrar el tour inicial después de reiniciar la app actualizada.

**Biblioteca**
- Se corrigieron portadas de números y hero para que sigan visibles después de editar el nombre de una serie que mueve el archivo a una carpeta renombrada.
- Se mejoró la carga de portadas para que las portadas visibles aparezcan en un orden más natural de arriba abajo.

**Interfaz**
- Se mejoraron los layouts de popups localizados para que las etiquetas y mensajes traducidos largos encajen y se lean mejor.
- El onboarding ahora se puede cerrar con **Esc** y navegar con las flechas, para recuperarse mejor si la ventana se abre fuera de pantalla.
