**機能**

**言語とローカライズ**
- **設定 -> 一般** に **アプリ言語** オプションを追加しました。
- 初回起動時に対応するシステム言語を使用できるようになりました。
- 上部バー、リーダー、ポップアップ、設定、メタデータダイアログ、ヘルプ、What's new のローカライズ済みテキストを追加しました。
- 英語、スペイン語、ドイツ語、フランス語、日本語、韓国語、中国語（簡体字）のオンボーディング素材を追加しました。

**ヘルプとリリースノート**
- ヘルプ内容は、単一のハードコードされた UI コピーではなく、同梱されたローカライズ済みデータファイルから読み込まれるようになりました。
- **ヘルプ** と **What's new** は選択中のアプリ言語に従い、英語へフォールバックします。
- 今後の更新でバージョン履歴を残せるよう、パッチノート作成ルールを追加しました。

**アップデートと portable app**
- アプリ設定は portable な **ComicPile.ini** 設定ファイルをより一貫して使用するようになりました。
- 利用可能な更新、ダウンロード進行状況、インストールの文脈が分かりやすくなるよう、更新ポップアップを改善しました。
- 既存のライブラリデータと設定を保持しながら、portable 更新をより安定して適用できるようにしました。

**リリースパッケージ**
- portable パッケージに **DjVu** runtime サポートを同梱しました。
- リリースパッケージ生成をより決定的にしました。

**修正**

**インターフェース**
- ウィンドウタイトルから prototype ラベルを削除しました。
- 長い翻訳テキストがより収まりやすく読みやすくなるよう、ローカライズ済みポップアップのレイアウトを改善しました。
- 古い placeholder ラベルを削除し、誤字のある asset パスを正規化しました。

**設定とオンボーディング**
- 重複していたデフォルト読書モード設定を削除しました。
- 設定リセット時にオンボーディング状態が誤ってリセットされないようにしました。
- オンボーディングを **Esc** で閉じ、矢印キーで操作できるようにしました。

**リーダーと検証**
- リーダー検証フローの QML warning を削除しました。
